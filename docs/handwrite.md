# 手撕记录

> 每次手撕结束后 1 分钟内填，不补写、不美化。这份表到第 13 周模拟面试时，能直接看出哪类题反复卡。

## 怎么用

| 项 | 规则 |
|---|---|
| 遍次 | 每题至少 3 遍：首做（允许卡住）→ 3 天后重做 → 第 13 周考前一遍 |
| 用时 | 从读题到代码可运行，含思考；不含配环境、调编辑器 |
| 独立程度 | **A** 独立完成 / **B** 提示后完成 / **C** 看完题解默写 |
| 卡点 | 写「下次怎么绕过」，不写「不够熟练」这种没法执行的话 |
| 提速目标 | 第二遍用时 ≤ 第一遍的 60%；第 6 周起中等题稳定在 30–40 分钟 |

**为什么规定遍次**：速度来自重做，不来自刷新题。同一题隔 3 天重做，通常能砍一半时间；刷 100 道新题不如 30 道各做 3 遍。

## 与计划的关系

- **题目来源**：`13周逐日任务清单.md` 附录 D 的 68 道清单。
- **每日时长**：W1–W2 60min、W3–W6 45min、W7–W13 30min（见 `学习日历.md`）。
- **门 F 要求**：30 分钟内出可运行代码，被追问能讲复杂度与边界。
- **卡点分类**：思路（不知道用啥结构）/ 实现（知道但写不出）/ 边界（漏了空数组、重复元素）/ 表达（写得对但讲不清）。哪类多，就补哪类。
