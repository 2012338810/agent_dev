# 13 周逐日任务清单 · 逐日细则（仓库级代码修复 Agent）

> 每天只看当天那一节。每节包含：**今天要学什么（带目标等级）→ 怎么动手 → 达到什么程度算过关 → 3 道验证题**。

## 使用说明

| 项 | 说明 |
|---|---|
| 周期 | 13 周 × 7 天，共 91 天 |
| 每日 4.5h | 手撕 30min + 八股 30min + 编码 2.5h + 笔记 30min + **验证 30min** |
| 周末 | 6–8h 大块攻坚 + 周日晚 90min 周考核 |
| 总时长 | 13 周 × 31.5h ≈ **410 小时** |
| 状态差的日子 | 最小可执行版：手撕 30 + 编码 60 + 验证 30，其余可砍。**连续性优先于强度** |
| 没完成的某天 | 不要整体顺延，在本周末补；周计划不变 |

**三条铁律**

1. AI 只当老师，不当打字员。每个函数先自己写，卡住 20 分钟再问，问「为什么」不问「给我代码」。
2. AI 给的代码必须能逐行解释，解释不了就删掉重写。
3. 每周做一次白板测试：关掉 AI，从空白文件写出本周核心逻辑。

## 掌握程度怎么衡量（L1–L4）

本文每个知识点都标了目标等级。**只学到等级要求为止，不许多学**——这是三个月能跑完的前提。

| 等级 | 名称 | 判据（必须能当场演示） |
|---|---|---|
| **L1** | 认得 | 知道它解决什么问题、什么时候该想起来用；能跟着文档跑通示例 |
| **L2** | 会用 | 不看教程、只查 API 文档就能写出来；能改参数、能读懂别人的同类代码 |
| **L3** | 讲清 | 合上资料能回答三问：它解决什么问题？什么情况下不适用？为什么不用替代方案？ |
| **L4** | 手写 | 关掉 AI、关掉文档，30 分钟内从空白文件写出可运行版本 |

**注意**：L3 是面试的实际门槛，L4 只给少数核心能力（FastAPI 服务、Agent Loop、评测执行器、限流器）。大量知识点停在 L2 是正常的，不要因为在 L2 就焦虑。

## 每天 30 分钟验证怎么做

| 时长 | 动作 | 要点 |
|---|---|---|
| 10min | 合上所有资料，口头回答当天 3 道验证题 | 不许查文件；答不出就跳过，不要现场翻 |
| 10min | 只对照答错的那几题，找到准确出处 | 不要顺手把整章重读一遍 |
| 10min | 写下「一句话答案 + 边界条件」 | 一句话讲结论，再加「什么情况下不成立」 |

| 标记 | 判据 | 处理 |
|---|---|---|
| ✅ 掌握 | 能用自己的话讲清 + 举得出具体例子 | 归档 |
| 🟡 半懂 | 讲得出名词，讲不清为什么或举不出例子 | 当晚回看 15min，次日开头重答 |
| ❌ 未掌握 | 说不出或说错 | 记入 `verify.md`，周末重学 |

**硬规则**：同一题连续两次 ❌ 必须周末重学；每周 ❌ 超过 8 个，本周判「未达标」，周末补，不顺延；复述原文不算掌握。

| 时间分配 | 每段几分钟、哪里留互动 | L2 |
| 开头 | 30 秒说清「做了什么、多好」 | L3 |
| 白板 | 什么时候画图、画什么 | L2 |

**动手**
1. 写逐段要点（不写逐字稿），标注每段时长，总计 38–42 分钟。
2. 设计 3 个「引导追问」的钩子（故意留细节给面试官问）。
3. 计时讲一遍，录音，记录每段实际用时。

**验收**
1. 讲完在 40 分钟内，且核心数据都讲到了。
2. 开头 30 秒能让人听懂。
3. 有 3 个可被追问的钩子且你有准备。

**验证问答**
1. 40 分钟怎么分配？哪段最容易超时？
2. 开头 30 秒说什么？为什么不是自我介绍？
3. 白板什么时候用？画什么最有效？

## 第 3 天 · 12 道必答题

**今天结束时要能**：12 道高频问题各答 3 分钟，且有数字支撑。

| 学习项 | 要学什么 | 目标 |
|---|---|---|
| 题目清单 | 切分/RAG、定位难、死循环、工具失败、无标准答案评测、prompt 回归、注入、并发、成本、踩坑 | L3 |
| 答法 | 结论先行 + 数据 + 边界 | L3 |
| 不会时 | 承认 + 给出思路 | L2 |
| 反例 | 背模板的痕迹怎么避免 | L2 |

**动手**
1. 12 道题各写「结论 1 句 + 数据 2 个 + 边界 1 句」。
2. 挑最弱的 3 道，回去补对应数据（必要时补跑实验）。
3. 找人随机抽问，限时 3 分钟。

**验收**
1. 12 道都能答满 2 分钟不重复。
2. 每道至少有一个自己的数字。
3. 遇到没准备的题，能说出「我会怎么查/怎么验证」。

**验证问答**
1. 12 道里你最弱的三道？为什么弱？
2. 没有标准答案的题怎么答？
3. 被问倒时的正确姿势是什么？

## 第 4 天 · 模拟面试 1（录音自评）

**今天结束时要能**：发现 3 个具体的表达问题。

| 学习项 | 要学什么 | 目标 |
|---|---|---|
| 自评维度 | 结构、数据、语速、停顿、眼神（录屏） | L2 |
| 问题定位 | 卡壳处对应哪个知识漏洞 | L3 |
| 修正 | 改讲稿 vs 补知识 | L2 |

**动手**
1. 用手机录音/录屏，模拟面试官提问 12 道题。
2. 回听，标出：超过 5 秒的停顿、说了「嗯/那个」的地方、数据说不出的地方。
3. 列 3 个改进项，当天改讲稿。

**验收**
1. 找出至少 3 个具体问题（不是「讲得不好」）。
2. 每个问题有对应改法。
3. 重录同一题，明显改善。

**验证问答**
1. 录音里最大的问题是什么？
2. 语速和停顿怎么调？太快/太慢各说明什么？
3. 白板书写习惯要改什么？

## 第 5 天 · 模拟面试 2（真人追问）

**今天结束时要能**：被追问 3 层不慌，答案不掉链子。

| 学习项 | 要学什么 | 目标 |
|---|---|---|
| 追问层次 | 是什么 → 为什么 → 不这么做会怎样 | L3 |
| 防守 | 不知道就承认，给出推理路径 | L3 |
| 深度 | 每个技术点准备到第 3 层 | L3 |
| 记录 | 被问倒的题当场记 | L2 |

**动手**
1. 找朋友/同事扮演面试官，按讲稿听 40 分钟 + 追问 20 分钟。
2. 让对方专挑「数字怎么来的」「为什么不用另一种」追问。
3. 记录所有卡住的点，按「知识/数据/表达」分类。

**验收**
1. 追问三层时至少 70% 能答。
2. 卡住的点归类清楚，知识类当天补。
3. 对方反馈能说出「哪一块最像背的」。

**验证问答**
1. 追问三层分别是哪三层？你哪层最弱？
2. 最狠的一问是什么？你怎么答的？
3. 补漏怎么排优先级？

**验收**

**验证问答**

2. 投递表记哪些字段？为什么面试后 24 小时内必须复盘？
