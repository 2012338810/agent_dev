# Agent 开发求职：四个月（18 周）逐日学习计划

## 目标与使用方式

适用起点：有验证工作经验，Python、后端和数据库需要恢复。每天投入约 4 小时，18 周（约四个月）后开始投递初级 Python / 大模型应用 / Agent 应用开发岗位。

共 126 天（18 周），其中第 5、9、15 周为缓冲周：一半时间按当周清单补强，一半时间补欠账与复盘；若进度已追平，缓冲周可改为休息或提前进入下一阶段。D1 从正式开始学习当天计算。全程围绕一个项目：**需求文档与测试用例助手**。前三周使用手写示例数据，第六周开始接入模型。

每日时间：学习 45 分钟，编码调试 135 分钟，验收测试 45 分钟，提交代码与记录 15 分钟。每周第七天验收、补欠账，提前完成可休息。

模型 API 花费：接入模型前为账户设置花费上限；调试用短样例，批量评估优先选低价模型并缓存结果，避免调试循环持续烧钱。

最终流程：导入需求 → 提问并查看引用 → 生成测试用例 → 检查覆盖与重复 → 保存和导出。上传、保存、导出采用固定程序逻辑，按需查询与生成使用模型和工具。
