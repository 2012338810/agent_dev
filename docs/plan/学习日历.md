## 顺延与补漏规则（照抄原计划，防止走偏）

1. 某天没完成 → **不要整体顺延**，在本周末补；周计划不变。
2. 同一验证题连续两次 ❌ → 周末必须重学。
3. 每周 ❌ 超过 8 个 → 本周判「未达标」，周末补，不顺延。
4. 每周一次关 AI 白板测试：从空白文件写出本周核心逻辑。
5. 门 A / B / C / D / E / F 是硬门，过了才往后走；过不了按附录 B 延期或降级。
