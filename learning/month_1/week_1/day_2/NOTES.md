# D2 笔记（2026-11-24 · 字符串、列表、字典、集合）

> 规则：编码结束后 30 分钟内写完，不补写、不美化。踩坑一条必须能讲给面试官，否则不算。

- 学到：字符串不可变的真正原因——哈希稳定（才能当字典键）、共享安全、可驻留缓存；`sort()` 返回 `None` 是刻意设计，用返回值区分"原地操作 / 返回新对象"；列表查找 O(n) vs 字典 O(1)，建索引是"一次成本换高频查询"。
- 卡在：`strip()`/`split()` 当场口误；`case[0]` 拿整数当字典键报 `KeyError`；中文优先级直接排序走 Unicode 码点，需要 `RANK` 映射成数字。
- 明天第一件事：D3 条件、循环、函数（筛选、字段检查、统计函数）；如果 D2 感觉不牢，先不看资料盲写一遍 `cases.py` 热身。
- 踩坑（能讲给面试官的才算）：
  1. 函数"没结果"的返回语义必须唯一：`None` 和 `[]` 混用会逼调用方写两套判断（`filter_by_priority` 空列表返回 `None` 的修复实录）。
  2. `list.sort()` 返回 `None`，`new = old.sort()` 是经典坑；Python 内置 API 用返回值表达"有没有新对象"，自己设计函数也该这么诚实。
  3. "以为改完了"不算完成：今天两次实际是"替换漏空格只改了 1/5 处"就以为全改了，必须以运行输出为准——自己的验收规则"实际运行验证"就是为这种情况定的。
